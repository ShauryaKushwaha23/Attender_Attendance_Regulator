# Attender_Attendance_Regulator
Attender is a smart attendance tracker built with HTML, CSS, and JavaScript. Track subject-wise attendance, calculate safe absences, manage timetables, monitor progress with interactive charts, and get personalised recommendations—all through a modern, browser-based interface with local data storage.
